# UIMSD visual preservation and acceptance

Scope: presentation and navigation only. Recorder, query calculations, raw records, saved formats, export semantics, seeded gameplay and inventory limits are unchanged.

## Source inspection

Reviewed the scene, Home, shared style, table, access gate, text layout, Ask builder, Choices, Columns, Filter, Guide, shared list, Options, Reports, row sheets, Sort, Status, text windows/input and guide topics. Existing SPD Rankings/Journal/button/window/sprite conventions were used. Source review is not device acceptance.

| Area | Functionality retained | Presentation change |
| --- | --- | --- |
| Home | Every original card/link, summary aggregate, records, difficulty and character drilldowns | Native rows/icons, aligned values, separate details, direct existing-view links |
