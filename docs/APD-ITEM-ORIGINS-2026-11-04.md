# Unidentified equipment origin — November 4, 2026

Implemented for unidentified equipable gear and wands in their existing inventory/equipment item descriptions. Identification immediately hides the line; it does not delete the stored fact. No enchantment, curse, upgrade, item-class identity or stat is used to construct the origin line.

## Actual classification and sources

The inspected source distinguishes Iron Key room doors from Golden Key locked chests and Crystal Key chests/doors. Examples: an Armory or Crypt has an Iron Key entrance; CrystalVault has an Iron Key entrance and Crystal Key chests; CrystalChoice has Iron and Crystal Key doors; CrystalPath has Crystal Key doors. SecretChestChasm uses a Golden Key chest, not a Golden Key room door. The explicit labels cover the actual ordinary, special, secret, quest, passage, entrance and exit room classes, including treasury, armory and crypt. There is no generic invented Locked Room classification.

A generated chest item can read `Found on Floor 8, Golden Key chest in Armory (Special room, Iron Key door).` Monster, mimic, animated-statue, shop stock, tomb, skeletal/adventurer remains, quest reward, bonus and crafted sources have separate labels. Unknown room names are omitted, never printed as Java class names. Branch identity is preserved alongside floor number.

Final level-generation heaps are captured after painting/chest sealing, independently of whether statistics recording is enabled. Runtime source hooks cover ordinary and expanded monster drops, mimic loot, statue drops, chest opening, purchases, quest selection, crafting and transformation. General Level.drop does not assign a new origin. Additive `apd_item_origin_v1` item bundle data preserves the original across ordinary drops, pickup, equipping, duplicates, splits, Gathering and Forwarding. Mixed/partly unknown stack sources are labelled conservatively. Bones entering a new run discard the previous hero's location so the current run records remains at their actual location.

## Ongoing runs and already-owned gear

No new run or re-pickup is required. Existing recorder replay rebuilds a location/source projection by exact item UID and applies it to backpack and equipped objects during normal reconciliation. Only generation locations matched to that same item's public observation or actual acquisition cell can supply a room. Hidden generation alone cannot expose an unseen room. A public historical pickup/shop event can supply a floor/source without guessing a missing room. Split/copy/transform/merge lineage is respected; events after the loaded save and abandoned events stay behind the existing canonical replay gates. Once restored, the origin is saved on the item.

Older gear without sufficient history remains unlabelled; floor-only historical pickup evidence is explicitly described as a pickup with original source unrecorded. The implementation cannot truthfully recover facts never saved. Legacy unknown items do not acquire an invented original location merely by being dropped and picked up again. Raw histories, saves' existing contents, statistics and scoring are not rewritten.
